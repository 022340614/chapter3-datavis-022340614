# 第3章 数据可视化网站

基于《数据可视化》课程第3章内容构建的交互式数据可视化网站，展示各种数据可视化技术和图表类型。

## 项目概述

本项目实现了第3章中所有的数据可视化示例，包括：

- 正弦曲线和余弦曲线
- 2019年内地电影票房排行榜
- 支付宝月账单报告
- 汽车速度与制动距离的关系
- 高二年级各班男女生英语成绩评估
- 2013-2019财年阿里巴巴淘宝和天猫平台GMV
- 果酱面包配料比例

## 技术栈

- **前端**: HTML5, CSS3, JavaScript
- **图表库**: Chart.js
- **响应式设计**: 支持桌面和移动设备
- **交互功能**: 选项卡切换、悬停提示、动画效果

## 项目结构

```
chapter3-datavis-022340614/
├── index.html          # 主页面文件
├── charts.js           # 图表配置和数据处理
├── README.md           # 项目说明文档
└── start-server.bat    # Windows服务器启动脚本
```

## 功能特点

1. **完整的可视化示例**: 包含第3章所有7个主要示例
2. **交互式界面**: 选项卡切换不同图表
3. **响应式设计**: 适配不同屏幕尺寸
4. **美观的UI**: 现代化的渐变背景和卡片设计
5. **详细说明**: 每个图表都配有文字说明

## 快速开始

### 方法一：直接打开（推荐）
1. 双击 `index.html` 文件
2. 在浏览器中查看网站

### 方法二：使用本地服务器
1. 双击 `start-server.bat` 启动本地服务器
2. 浏览器自动打开 `http://localhost:8080`

## 图表说明

### 1. 正弦曲线和余弦曲线
- 展示数学函数图像
- 包含坐标轴标签、刻度、标题、图例
- 网格线、参考线和注释文本

### 2. 电影票房排行榜
- 水平条形图展示票房数据
- 2019年内地电影票房前15名
- 单位：亿元人民币

### 3. 支付宝月账单报告
- 饼图展示消费类别比例
- 8个消费类别：购物、人情往来、餐饮美食等
- 百分比显示

### 4. 汽车制动距离
- 散点图展示速度与制动距离关系
- 速度范围：10-200km/h
- 包含网格线辅助观察

### 5. 英语成绩评估
- 分组柱状图对比男女生成绩
- 高二6个班级数据
- 包含全体平均成绩参考线

### 6. 阿里GMV数据
- 柱状图展示GMV增长趋势
- 2013-2019财年数据
- 单位：亿元人民币

### 7. 面包配料比例
- 饼图展示配料比例
- 8种原料：面粉、全麦粉、酵母等
- 重量和百分比显示
